# 双动平台混联踝关节康复机器人

基于 **双动平台 + 混联机构 + 多自由度运动控制** 设计的踝关节康复机器人，用于实现踝关节多方向运动训练及步态联动康复。

机器人采用三自由度机构设计，通过双动平台协同运动实现踝关节 **背屈/跖屈、内翻/外翻、内收/外展** 等康复动作，并结合运动学模型和上位机控制系统，实现机器人运动控制与康复训练。

---

## 1. 项目实现

主要完成内容：

- 根据踝关节 **3 自由度运动需求** 完成机器人机构方案设计
- 确定机器人结构尺寸并建立运动学模型
- 使用 SolidWorks 完成机器人三维结构设计及二维工程图绘制
- 完成电机、传感器及相关电气元件选型
- 建立机器人运动学模型并完成控制算法部署
- 编写机器人上位机控制程序，实现机构运动控制
- 实现踝关节多方向康复运动及步态联动训练

主要康复模式：

- **背屈 / 跖屈**
- **内翻 / 外翻**
- **内收 / 外展**
- **步态联动**

---

## 2. 系统整体架构

```text
康复训练指令
      │
      ▼
   上位机控制
      │
      ├── 康复模式选择
      ├── 目标运动轨迹
      └── 运动参数设置
      │
      ▼
   运动学模型
      │
      ├── 位姿计算
      ├── 机构运动映射
      └── 驱动参数计算
      │
      ▼
   电机驱动系统
      │
      ├── 步进电机
      └── 电动推杆
      │
      ▼
 双动平台混联机构
      │
      ├── 直线型 Delta 机构
      ├── 小腿固定平台
      ├── 动平台
      └── 重力平衡机构
      │
      ▼
   踝关节康复运动
      │
      ├── 背屈 / 跖屈
      ├── 内翻 / 外翻
      ├── 内收 / 外展
      └── 步态联动
      │
      ▼
 编码器 / 六维力传感器
      │
      └──────────► 状态反馈
```

最终形成：

**康复指令 → 运动学计算 → 电机驱动 → 混联机构运动 → 踝关节训练 → 状态反馈**

的踝关节康复机器人控制系统。
