# VR 体感机械臂控制系统

基于 **PICO VR + Unity + ESP32 + 多自由度机械臂** 实现的体感机械臂遥操作系统。

系统通过 VR 手柄获取操作者手部的空间位置与姿态，
在 Unity 中完成坐标系转换、运动映射和机械臂逆运动学计算，
再通过串口将目标关节角发送至 ESP32，
由 ESP32 驱动舵机，实现实体机械臂对 VR 手柄运动的实时跟随。

🎥 项目演示视频：

[点击查看机械臂演示视频](./AR机械臂.mp4)

主要实现效果：

- VR 手柄实时控制机械臂运动
- Unity 中获取手柄空间位置
- 根据目标位置计算机械臂关节角
- Unity 虚拟机械臂与实体机械臂同步运动
- ESP32 实时接收关节角并驱动舵机

## 2. 系统整体架构

```text
PICO VR Controller
        │
        │ Position / Rotation
        ▼
      Unity
        │
        ├── VR 手柄位姿获取
        ├── 坐标系转换
        ├── 运动范围映射
        ├── 逆运动学 IK
        └── 关节角计算
        │
        ▼
   Serial Communication
        │
        ▼
      ESP32
        │
        ├── 串口数据解析
        ├── 舵机角度映射
        └── PWM 输出
        │
        ▼
 Servo1 / Servo2 / Servo3
        │
        ▼
    实体机械臂
