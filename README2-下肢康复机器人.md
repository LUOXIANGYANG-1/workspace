# 下肢康复机器人系统

基于 **多相机视觉 + Xsens IMU + 步态识别模型 + 悬吊康复机器人** 实现的下肢步态识别与康复训练系统。

系统通过四相机和 7 个下肢 IMU 同步采集患者运动数据，
利用步态识别模型提取关键步态参数并评估患者康复状态，
再根据评估结果动态调节悬吊减重力和水平跟随位置，
实现面向患者步态状态的闭环康复训练。

---

## 1. 项目实现

主要实现功能：

- 四相机与 7 个 Xsens MTw Awinda IMU 同步采集下肢运动数据
- 完成多相机标定、IMU 标定及多传感器时间同步
- 基于多模态数据训练步态识别模型
- 实时提取步态参数并评估患者步态状态
- 根据步态评估结果动态调节悬吊减重力
- 控制悬吊机构水平跟随患者运动
- 结合张力与步态反馈实现闭环康复控制

---

## 2. 系统整体架构

```text
四相机 + 7个下肢IMU
        │
        │ 图像 / 惯性数据
        ▼
   数据采集与同步
        │
        ├── 相机内外参标定
        ├── IMU 姿态标定
        └── 多传感器时间同步
        │
        ▼
    步态识别模型
        │
        ├── 步态参数提取
        ├── 步态状态识别
        └── 康复状态评估
        │
        ▼
     悬吊控制策略
        │
        ├── 减重力调节
        └── 水平位置跟随
        │
        ▼
翠欧 FLEX6P600 控制器
        │
        │ EtherCAT
        ▼
   闭环步进电机
        │
        ├── 竖直方向控制
        └── 水平方向控制
        │
        ▼
   悬吊康复机器人
        │
        │ 张力 / 步态反馈
        └──────────────► 闭环调节
```

最终形成：

**多模态步态采集 → 步态识别 → 康复评估 → 悬吊控制 → 状态反馈 → 动态调节**

的下肢康复机器人闭环训练系统。
